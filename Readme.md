# Mohak Gupta AIML Application Project
This project basically takes user input of details of a titanic passenger and gives an output of whether they survived the wreck or not as well as an actual probability alongside the yes no answer.

## How to use
Run the app.py file after using pip install to get the required libraries from requirements.txt (or just installing the .venv alongside) and then provide input in the web ui to get the answers!

# Concepts and Libraries used
Logistic Regression for Binary Classification problem, pandas for dataframes, sklearn (which has logisticreg method) for various tasks like performance metrics (printing currently removed), Column Scaling, Filling Missing Data with medians, Categorical to Numerical Conversion.
